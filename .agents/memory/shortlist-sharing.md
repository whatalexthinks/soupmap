---
name: Shortlist sharing privacy
description: Privacy and snapshot expectations for saved-shop sharing.
---

Treat shared shortlists as explicit, bearer-link snapshots, not a synced collection or a replacement for the recipient's saves.

**Why:** Saved places are private device-local choices; sharing only chosen shops must not expose the rest or change a friend's existing collection. A serverless link cannot be revoked after someone receives it.

**How to apply:** Keep opt-in selection with nothing preselected, explain that anyone with the link can view it and later save changes do not revoke it, and never automatically import shared IDs into local saves. Do not add server synchronization or access-control claims without a separate product decision.
